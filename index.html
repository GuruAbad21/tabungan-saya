Pengaturan Cloud & Sinkronisasi

Masukkan Kode Sinkronisasi dari perangkat lama Anda di bawah ini untuk menyatukan dan mengakses data yang sama secara live.

⚠️ 2 Langkah Wajib di Firebase Console Agar Online:

  1. Aktifkan Login Anonim (Sangat Penting):
    Buka konsol Firebase -> Menu Authentication -> Tab Sign-in method -> Klik Add new provider -> Pilih Anonymous (Anonim) -> Klik tombol slide Enable -> Klik Save.
  2. Buat Database Firestore:
    Buka menu Firestore Database -> Klik Create database -> Pilih lokasi -> Pilih Start in test mode (Mulai dalam mode pengujian agar bisa tulis-baca gratis tanpa proteksi akun) -> Klik Create/Enable.
